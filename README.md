# RO Module

ラグナロクオンライン公式サイト・公式ツール向けの Chrome / Edge 拡張機能（非公式のファンツール）。

- アイテム名・エンチャント名にマウスを乗せると説明を表示（アイテムはクリックで公式ツールのページを開く）
- 公式サイト・公式ツールなどの上部に、よく使うページへのリンクバーを表示
- お知らせ一覧とゲーム起動ページに、トップページのバナーを表示
